# P2 — Offline hypothesis generation (paper)

**Capital:** paper. **LLM role:** offline strategy-hypothesis generation (human reviews each).

## Goal

Use the slow-loop LLM to propose strategy hypotheses **offline**, and validate them with the
same anti-overfitting discipline as any human idea — without letting batch-testing manufacture
false positives.

## Scope

- LLM proposes hypotheses offline; a human reviews each before it enters backtest (Inv. 1, 8).
- Each candidate goes through backtest + out-of-sample + walk-forward (§8).
- The **AI trade journal (§15)** records every hypothesis tried and its outcome, including the
  **count of hypotheses tried** for the multiple-testing correction.

## DONE-GATE

- [ ] P0–P1 gates still hold (re-proven from clean).
- [ ] **≥1 LLM-proposed strategy independently backtested + walk-forward validated.**
- [ ] **Multiple-testing correction applied** (deflated Sharpe / higher bar the more variants
      were tested — §5). A strategy that passes walk-forward in isolation may still be noise
      given how many were tried.
- [ ] Sample-size gate met (≥ ~100–200 trades).
- [ ] Net-of-cost edge clears all-in cost incl. **tax** (§11/§15).

## Status (2026-06-27) — validation machinery BUILT & tested; needs Ollama + a human in the loop

Code complete and tested offline (no Ollama):
- **AI trade journal** `src/llm/journal.py` — append-only hypothesis memory (§15);
  `count_trials()` is the honest §5 denominator (validated|rejected, not proposed).
- **Multiple-testing correction** `backtest/multiple_testing.py` — Probabilistic + Deflated
  Sharpe (Bailey & López de Prado), own `norm_cdf`/`norm_ppf` (no scipy). The bar rises with the
  number of trials; non-normal returns penalised.
- **Validation harness** `backtest/hypothesis.validate_hypothesis` — walk-forward → per-trade
  Sharpe/skew/kurtosis → DSR vs the journal's trial count → VALIDATE only if the sample-size gate
  passes AND DSR ≥ threshold; every attempt is journalled (so it counts against later candidates).
- **Proposer** `src/llm/hypothesis_gen.py` — offline LLM ideation, **human-gated** (Inv. 1/8),
  strict parameter budget enforced (over-budget proposals dropped).

**Remaining (operational, needs Ollama + a human):** run the proposer to generate candidates,
**a human approves each**, run `validate_hypothesis` on real bitbank BTC/JPY history, and clear
the gate with ≥1 validated strategy whose **net-of-cost-and-tax** edge survives the §5 correction.
No historical result is trusted without the deflation (§5).
