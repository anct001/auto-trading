# P2 — Offline hypothesis generation (paper)

**Capital:** paper. **LLM role:** offline strategy-hypothesis generation (human reviews each).

## Goal

Use the slow-loop LLM to propose strategy hypotheses **offline**, and validate them with the
same anti-overfitting discipline as any human idea — without letting batch-testing manufacture
false positives.

## Scope

- LLM proposes hypotheses offline; a human reviews each before it enters backtest (Inv. 1, 8).
- Each candidate goes through backtest + out-of-sample + walk-forward (§8).
- The **AI trade journal (§15)** records every hypothesis tried and its outcome, including the
  **count of hypotheses tried** for the multiple-testing correction.

## DONE-GATE

- [ ] P0–P1 gates still hold (re-proven from clean).
- [ ] **≥1 LLM-proposed strategy independently backtested + walk-forward validated.**
- [ ] **Multiple-testing correction applied** (deflated Sharpe / higher bar the more variants
      were tested — §5). A strategy that passes walk-forward in isolation may still be noise
      given how many were tried.
- [ ] Sample-size gate met (≥ ~100–200 trades).
- [ ] Net-of-cost edge clears all-in cost incl. **tax** (§11/§15).
