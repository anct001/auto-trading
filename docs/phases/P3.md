# P3 — Monitor / orchestrate (paper) — the last paper gate

**Capital:** paper. **LLM role:** monitor / orchestrate within deterministic guardrails.

## Goal

Run the full system continuously in dry-run long enough to trust its signal behavior and
operational stability. **This is the gate immediately before real capital (P4).**

## Scope

- Shadow mode (§15): a new/modified strategy runs in shadow (hypothetical P&L, never trades)
  before promotion — a relative screen, systematically optimistic on fills (§2).
- Operator dashboard + decision log + circuit-breaker status live (§12).
- Deterministic guardrails; the LLM monitors/orchestrates but never gates a trade (Inv. 2).

## DONE-GATE

- [ ] P0–P2 gates still hold (re-proven from clean).
- [ ] **≥ N_days (default 30) continuous dry-run, no crash.**
- [ ] **Dry-run signal metrics ≈ backtest.**
- [ ] Restart-safety verified: kill mid-trade → clean recovery, no double-trade (§9).
- [ ] **Note:** dry-run does NOT validate fill realism (§2) — that waits for P4.

Passing P3 unlocks the §14 go-live checklist. Real capital is touched only after that checklist
passes with recorded human sign-off (Inv. 4, 8).
