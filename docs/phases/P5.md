# P5 — Scale slowly

**Capital:** scale slowly. **LLM role:** unchanged (research / decision support only).

## Goal

Increase size only as live, risk-adjusted performance and capacity justify it — each increase
human-approved. Leverage may be *considered* here for the first time, within legal caps.

## Scope

- Capacity / liquidity re-check before every size increase (§5): an edge at $1k can vanish at
  $100k as slippage/impact scale. Re-test slippage at the new size.
- Leverage, if ever enabled, capped to the lower of the operator's limit and the jurisdiction's
  legal max (Japan/JFSA commonly 2x — §11), with its own tighter drawdown gate.

## DONE-GATE (per increase — this gate repeats)

- [ ] Sustained positive **live** risk-adjusted performance over a meaningful window (§0).
- [ ] Capacity check passed for the intended new size (§5).
- [ ] **Human sign-off recorded for this specific increase** (Inv. 8).
- [ ] Demotion rule still armed (§6): breach the live band → auto-revert to paper.

Scaling stays gated; the kill-switch stays sacred; leverage stays within legal caps.
