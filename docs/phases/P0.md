# P0 — Data harness (current phase)

**Capital:** none. **LLM role:** none.

## Goal

A clean, reproducible data + backtest foundation with one deliberately dumb strategy, so the
pipeline runs end-to-end and every later phase has trustworthy ground truth.

## Scope (build order — §7)

1. **Data layer (§2):** ccxt OHLCV fetch (closed candles only) → Parquet store, UTC,
   candle-close aligned.
2. **Data-quality gate (§8.1):** quarantine duplicate/out-of-order timestamps, non-positive
   prices, implausible single-candle spikes (>N×ATR), volume anomalies. A quarantined candle
   is never used for a signal or trade. **TDD.**
3. **Backtest harness (§8):** Freqtrade integration with a **StaticPairlist** (reproducibility),
   the operator's **actual fee tier**, and non-zero slippage.
4. **One dumb strategy (§5):** EMA crossover, 1–2 params, via the single feature path (§15).
5. **Dry-run (§8.9):** continuous forward run; signal metrics tracked.

## DONE-GATE (prove, do not assert — §8)

- [ ] OHLCV downloaded from the target exchange; Parquet; gaps / UTC / candle-close verified.
- [ ] Data-quality gate rejects/quarantines bad candles (unit-tested, red→green).
- [ ] Costs modeled: actual fee tier + explicit non-zero slippage. Zero cost = invalid.
- [ ] No look-ahead: signals act only on closed candles.
- [ ] Out-of-sample + walk-forward split done.
- [ ] Sample size ≥ ~100 trades AND a multi-regime window.
- [ ] Metrics computed: CAGR, max drawdown, Calmar, Sharpe, Sortino, win rate, profit factor,
      expectancy, trade count (drawdown/Calmar primary).
- [ ] **Reproducible:** identical reruns with a pinned StaticPairlist, data, seeds, config.
- [ ] Forward dry-run running; **signal** metrics ≈ backtest (fills NOT validated — §2).

**Reminder:** a green backtest number is not proof. Reproducibility + a matching forward
dry-run is. Fill realism remains unproven until P4.
