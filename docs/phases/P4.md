# P4 — Tiny real capital

**Capital:** the smallest meaningful amount, real. **LLM role:** research + decision support only.

> 🚦 **The §14 go-live checklist is the gate into this phase.** Every box checked, human
> sign-off recorded, before any real capital. Spot only, no leverage, trade-only keys.

## Goal

Observe **fill realism** for the first time (dry-run never validated it — §2), under live
risk controls and the smallest meaningful capital.

## Scope / what becomes real

- Live exchange connection (§10): correct entity (Binance Global vs Japan), endpoint confirmed,
  trade-only + withdrawals-disabled + IP-whitelisted key, secret vaulted/git-ignored.
- Exchange-side protective stops attach at fill and survive a killed local process (§4).
- Kill-switches, daily limits, drawdown gate, de-peg guard, dead-man's switches all live-tested.
- Capital-on-exchange cap set; excess-sweep procedure defined (§4).

## DONE-GATE (≡ §14 go-live checklist)

See [`../MASTER_DRIVER.md`](../MASTER_DRIVER.md) §14 — the authoritative checklist. Highlights:

- [ ] P0–P3 gates re-proven from clean.
- [ ] Risk-engine drills each actually fired (per-trade, correlation/beta, soft+hard daily,
      drawdown kill-switch, circuit breakers).
- [ ] Naked-position test passed (stop survives a killed process).
- [ ] Manual-order path verified to pass the risk engine (over-limit order rejected).
- [ ] Order feasibility verified (minNotional/lot/tick vs 0.5% size; sub-minimum → skip, not
      round up); three-way tension (capital ↔ 0.5% ↔ ≥100 trades) actually holds.
- [ ] De-peg guard live-tested; human-heartbeat dead-man's switch + demotion-to-paper configured.
- [ ] After-tax edge modeled; jurisdiction / ToS / tax confirmed by the operator.
- [ ] **Human sign-off recorded.**

**Demotion (§6):** if live performance deviates from backtest expectation beyond a threshold
over a window, the deployment auto-reverts to paper. A decayed-edge strategy is retired.
